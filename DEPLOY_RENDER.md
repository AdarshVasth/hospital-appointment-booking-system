# Deploy Clearway Hospital to Render

1. Sign in at https://dashboard.render.com/ and connect your GitHub account.
2. Choose **New > Blueprint**, select `AdarshVasth/hospital-appointment-booking-system`, and approve the `render.yaml` plan.
3. Check the displayed PostgreSQL and web-service pricing before confirming. Free-tier availability and database expiry depend on Render's current offerings.
4. Wait for the build and deployment to finish. Render displays the public `https://...onrender.com` URL.
5. Open the Render web service **Shell** (if available on your plan) and run `python manage.py seed_demo` followed by `python manage.py setup_admin`. Enter the admin password interactively, never in GitHub.
6. If Shell isn't available, use a one-time secure admin provisioning workflow with protected Render environment variables and remove them immediately after setup. Do not add credentials to code or the public repository.
7. Test `/admin/`, patient login, appointment creation, and persistence after a restart.

## Production notes
- The deployment uses PostgreSQL via `DATABASE_URL`; local development still uses SQLite.
- `DJANGO_SECRET_KEY` is generated by Render, and HTTPS and CSRF protections are enabled.
- The build migrates the database and collects static files.
- Do not use this coursework demo for actual patient medical information without a security/privacy review.
- Render free database plans may expire; upgrade to a persistent paid database before storing important records.
